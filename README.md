# Schwarmwelt

Schwarmwelt is a multi-agent art and research project exploring how recurrent social practices and proto-cultural traces might emerge under controlled artificial conditions.

The repository preserves not only working software and positive partial effects, but also rejected mechanisms, negative gates, preregistrations, freeze states, controls, audits and methodological restarts. The history of failure is part of the work.

## Relation to Galerie der Unwahrscheinlichkeiten

Schwarmwelt is published here as an external trace of **UNW – Galerie der Unwahrscheinlichkeiten**. The website source of the Galerie is deliberately not part of this repository and is maintained separately.

## Status

This is an art project and methodological thought experiment. It is not a scientifically validated model of culture, consciousness or sociality.

The public laboratory version 0.1.0 is a stepwise Python simulation with 48 agents, four permeable zones, private state estimates, symbolic emissions, multi-pulse encounters, turnover, diagnostic views, recording/replay and interchangeable research modules.

The laboratory application is not a numerically identical port of the earlier Numba batch model. Results from the laboratory must therefore not be presented as replications of the earlier experimental line without separate validation.

## Repository map

- `lab/0.1.0/` — runnable laboratory application, tests, scenarios, plugins, example run and documentation
- `methodology/` — methodological closure of E-001 to E-004, dual-model workflow, restart documents and evaluation grids
- `experiments/e-001/` — documented archival gap; no reconstructed primary package is substituted
- `experiments/e-002r/` — readable material and references to large release/archival packages
- `experiments/e-003-d2/` — readable material and references to audit, freeze and result packages
- `experiments/e-004-prg/` — design, reviews, freeze declarations, control lock, results and reproduction audits
- `experiments/protosocial-dyad/` — separate later/parallel line originally stored as E004_ProtoSozialitaet_Dyade
- `praxislabor/` — methodological restart after E-004, candidate search and meta-gates
- `archive/manifests/` — hashes and package manifests
- `provenance/` — explicitly marked reconstruction/source material, separated from canonical research artefacts

Large immutable packages are prepared separately as release or archival assets instead of being committed as Git blobs.

## Holdout

The holdout and its unlock material are intentionally not included in the public staging set. The existence and closed status of the holdout are documented; its content remains excluded unless a later explicit decision ends that methodological restriction.

## Integrity and provenance

Files marked `REKONSTRUIERT` are reconstructions from preserved chat/source material. The label is part of the provenance and must not be removed. Historical package boundaries and negative results should remain visible.
