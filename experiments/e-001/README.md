# E-001 — archival gap


E-001 is documented in the later methodological closure as the first formal experiment in the E-series and is reported as having used 12 complete core runs.


At the time of publication preparation, the dedicated Drive folder `E-001` is empty and no separate primary package could be unambiguously identified as the formal E-001 archive.


Historical pilot, dyad and control packages exist, but they are not silently relabelled as E-001.


Therefore this directory intentionally records an archival gap.


If a primary E-001 package is later identified, it should be added only with an explicit provenance note showing why that package can be assigned to E-001. Until then, later summaries may describe E-001, but no reconstructed primary artefact should be presented as original.
